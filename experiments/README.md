# experiments/

This folder contains reproducible experiment scripts that use the `gr/` package.

## Common setup

Hardware runs require environment variables:

- `SPINQ_IP`, `SPINQ_PORT`, `SPINQ_USER`, `SPINQ_PASS`

Example (Linux/macOS):
```bash
export SPINQ_IP="..."
export SPINQ_PORT="..."
export SPINQ_USER="..."
export SPINQ_PASS="..."
